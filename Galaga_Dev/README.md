# Space Galaga — Win32 / C

Windows API와 **순수 C17**로 제작한 세로형 갤러그 스타일 슈팅 게임입니다.
그래픽은 Windows 기본 GDI로 직접 그립니다. 외부 엔진, C++, 이미지 파일, 추가 라이브러리는 사용하지 않습니다.
소스는 UTF-8로 저장되며, 주요 함수와 처리 방식에 한글 주석을 작성했습니다.

## Visual Studio 2022에서 실행

1. Visual Studio Installer에서 **C++를 사용한 데스크톱 개발** 워크로드를 설치합니다. C 컴파일러도 이 워크로드에 포함됩니다.
2. **MSVC v143** 도구와 **Windows 10 또는 11 SDK**를 설치합니다.
3. 루트의 `Space_Galaga.sln` 파일을 Visual Studio 2022로 엽니다.
4. `Debug` 또는 `Release`, `x64` 또는 `x86` 구성을 선택합니다.
5. **Ctrl+Shift+B**로 빌드한 후 **F5** 또는 **Ctrl+F5**로 실행합니다.

실행 파일은 `bin/x64/Release/Space_Galaga.exe` 등 선택한 플랫폼/구성 폴더에 생성됩니다.
x86 솔루션 구성은 내부적으로 프로젝트의 Win32 플랫폼을 사용합니다.
Release 실행 파일은 C 런타임을 정적으로 연결하므로 별도 런타임 설치 없이 실행할 수 있습니다.

Developer PowerShell for VS 2022에서는 다음 명령으로 빌드할 수 있습니다.

```powershell
msbuild .\Space_Galaga.sln /m /p:Configuration=Release /p:Platform=x64
```

## 조작

| 키 | 기능 |
|---|---|
| Enter | 시작 / 게임 오버 후 재시작 |
| 방향키 또는 WASD | 상하좌우 이동 (화면 하단 전투 영역) |
| Space 누르기 유지 | 연속 사격 |
| Shift 누르기 유지 | 느린 정밀 이동 |
| P | 일시정지 / 계속하기 |
| F11 | 전체 화면 / 이전 창 크기로 복귀 |
| R | 게임 오버 후 재시작 |
| Esc | 종료 |

다른 창으로 전환하거나 최소화하면 자동으로 일시정지됩니다. 돌아온 후 P를 누르세요.

## 게임 규칙

- 시작 목숨은 3개입니다. 피격하면 강화가 해제되고 2.5초 동안 무적이 됩니다.
- 기본 적은 8열 5행 편대로 등장하며 일부가 급강하하고 플레이어를 조준해 발사합니다.
- 적 종류별로 100 / 200 / 300점을 지급하며 급강하 중 격파 점수는 1.5배입니다.
- 적 7기 격파마다 P 아이템이 떨어집니다. 획득하면 50점과 12초간 3방향 사격을 얻습니다.
- 편대를 전멸시키면 2.5초 뒤 다음 스테이지가 시작됩니다.
- 5, 10, 15… 스테이지에는 체력 막대가 있는 보스가 등장합니다. 보스는 3,000점과 아이템을 줍니다.
- 스테이지에 따라 적 탄속과 공격 빈도가 증가하며, 반복 진행할 수 있습니다.
- 최고 점수는 프로그램 실행 중 유지되며 종료하면 초기화됩니다. 사운드와 디스크 저장 기능은 없습니다.

## 코드 안내

| 파일 | 역할 |
|---|---|
| `Space_Galaga/main.c` | Win32 창, 메시지 처리, 키 입력 전달, 타이머, 화면 비율 유지, GDI 더블 버퍼 관리 |
| `Space_Galaga/game.h` | 게임 상태, 적/탄환/입자/아이템 구조체, 공개 함수 |
| `Space_Galaga/game.c` | 게임 규칙, 적 AI, 원형 충돌, 효과, GDI 도형 및 한글 UI |
| `Space_Galaga/Space_Galaga.vcxproj` | VS2022 v143, C17, UTF-8, Unicode, x86/x64 빌드 설정 |

논리 해상도는 800×900이며 창 크기를 바꿔도 비율을 유지합니다.
기본 창은 기존의 150%인 1200×1350 클라이언트 영역을 요청하며, 모니터보다 크면 자동으로 최대화합니다.
폰트는 27 / 38 / 86px로 약 50% 확대했고, 기체·적·보스·탄환·아이템도 약 1.5배 크게 표시합니다.
상단 정보 패널, 두 줄 조작 안내, 일시정지/게임 오버 패널은 커진 글꼴에 맞춰 재배치했습니다.
충돌 판정은 기존의 작은 원을 유지하며, 확대된 도형이 패널에 겹치지 않도록 이동 영역과 편대 위치를 조정했습니다.
F11을 누르면 제목 표시줄과 작업 표시줄 없이 모니터 전체를 사용합니다.
업데이트는 성능 카운터를 이용한 1/120초 고정 간격으로 처리합니다.
탄환과 입자는 고정 배열의 비활성 슬롯을 재사용하며, GDI 객체는 사용 후 해제합니다.
`/TC`에 해당하는 `CompileAsC` 설정을 적용하여 모든 `.c` 파일을 C로 컴파일합니다.

## 게임 규칙 테스트

VS 2022의 **Developer PowerShell**을 x64 개발 환경으로 열고 프로젝트 루트를 기준으로 실행합니다.

```powershell
New-Item -ItemType Directory -Force obj/tests, bin/tests
cl /nologo /TC /std:c17 /utf-8 /W4 /WX /MTd /Od /RTC1 /Foobj/tests/ /Febin/tests/game_tests.exe tests/game_tests.c Space_Galaga/game.c /link /SUBSYSTEM:CONSOLE user32.lib gdi32.lib
./bin/tests/game_tests.exe
```

`tests/game_tests.c`는 이동 속도, 일시정지/포커스 상실, 강화와 발사,
피격/무적/게임 오버/재시작, 적 충돌과 점수, 스테이지 전환, 보스 생성을 검증합니다.
추가로 10분 분량의 가상 플레이에서 좌표와 적 수의 일관성을 검사합니다.
테스트에서도 Windows API와 C만 사용하며 창을 생성하지 않습니다.

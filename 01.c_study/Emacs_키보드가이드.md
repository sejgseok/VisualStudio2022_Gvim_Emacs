# Emacs 키보드 가이드 (C/C++ 공부 폴더)

- **작성일:** 2026-11-13 (2026-11-14: 글꼴과 색 `emacs_theme.el`, C/C++ 편집 편의 기능 `emacs_edit.el` 추가)
- **대상:** C/C++ 공부 폴더의 `emacs.bat`로 연 GNU Emacs 31.1
  - 설정은 `handmade.emacs`(Handmade Hero의 Casey 설정), `emacs_c_study.el`(공부 폴더용 빌드, 실행, 디버그 키), 그리고 `emacs_c_study.el`이 마지막에 읽는 `emacs_theme.el`(gvim과 같은 글꼴과 색)과 `emacs_edit.el`(gvim과 같은 C/C++ 편집 기능)이다.
  - 이 PC에는 `E:\Work\Dev\01.c_study`(독립 폴더)와 `E:\Work\Dev\02.handmade_dev\01.Dev_work\01.c_study`(Handmade Hero 작업 폴더 안) 두 곳에 같은 파일이 있다. 아래 예의 `E:\Work\Dev\01.c_study`는 쓰는 폴더의 경로로 바꿔 읽는다.
- **목적:** 마우스 없이 키보드만으로 C/C++ 코드를 쓰고, 빌드하고, 실행하고, 코드 사이를 옮겨 다니고, 복사·삭제·붙여넣기를 빠르게 하는 방법
- **관련 문서:** 같은 폴더의 `Emacs_C_C++_가이드.md`(환경 구성, 빌드, 실행, Visual Studio 디버깅 순서), `C_C++_빌드가이드.txt`(gvim으로 쓸 때)
- 이 문서의 키는 모두 이 PC에서 공부 폴더의 복사본으로 Emacs 31.1을 실제로 띄워 확인했다([18절](#18-확인-근거)).

> **먼저 알아 둘 점**
> 이 환경은 Casey의 설정이라 Emacs 기본 키와 다른 키가 많다. 인터넷의 일반 Emacs 설명과 다르니 주의한다.
> - `C-y`는 붙여넣기가 아니라 들여쓰기이다. 붙여넣기는 `C-f` 또는 `M-a`이다.
> - 복사는 `C-q`이고, `M-w`는 창 이동이다.
> - `TAB`은 단어 자동 완성이다(닫는 괄호 바로 앞에서는 그 뒤로 빠져나간다, [11절](#cc-편집-편의-기능-emacs_editel)).
>
> 헷갈리기 쉬운 키는 [3절](#3-기본-emacs와-다른-키)에 모았다.

## 1. 키 표기법과 기본 조작

| 표기 | 뜻 | 예 |
|---|---|---|
| `C-x` | Ctrl을 누른 채 x | `C-s` = Ctrl+S |
| `M-x` | Alt를 누른 채 x (Meta) | `M-m` = Alt+M |
| `M-X` (대문자) | Alt와 Shift를 누른 채 x | `M-N` = Alt+Shift+N |
| `C-M-x` | Ctrl과 Alt를 함께 누른 채 x | `C-M-a` |
| `S-x` | Shift를 누른 채 x | `S-<f5>` = Shift+F5 |
| `C-x C-s` | Ctrl+X를 눌렀다 뗀 뒤 Ctrl+S | 두 키를 차례로 누른다 |
| `C-x k` | Ctrl+X를 눌렀다 뗀 뒤 k | |
| `RET` | Enter | |
| `SPC` | 스페이스바 | `C-SPC` = Ctrl+Space |
| `DEL` | Backspace | `M-DEL` = Alt+Backspace |
| `TAB` | Tab | |
| `<up>` `<down>` `<left>` `<right>` | 화살표 키 | `C-<up>` = Ctrl+위 화살표 |
| `<prior>` `<next>` | Page Up, Page Down | |
| `<f5>` | F5 키 | `C-<f5>` = Ctrl+F5 |

기본 조작:

| 키 | 기능 |
|---|---|
| `C-g` | 지금 하던 명령 취소. 미니버퍼(아래 한 줄 입력 칸)에서 빠져나올 때도 쓴다. 이상하면 `C-g`를 두세 번 누른다 |
| `ESC ESC ESC` | 미니버퍼, 선택 상태 등을 모두 취소 |
| `M-x 명령 RET` | 이름으로 명령 실행. 이름 일부를 치고 `TAB`으로 완성한다 |
| `ESC` 다음 키 | `M-` 키 대신 쓸 수 있다. `ESC` `m` = `M-m` |
| `C-u` | 다음 명령에 숫자나 옵션을 준다. `C-u 5 C-n` = 다섯 줄 아래 |
| `C-x C-c` | Emacs 종료. 저장하지 않은 파일이 있으면 물어본다 |

> 한/영 키가 **한글** 상태여도 `C-`, `M-` 조합 키는 동작한다. 다만 `M-x` 뒤에 명령 이름을 칠 때나 파일 이름을 입력할 때는 **영문** 상태로 바꾼다.

> `C-z`는 Emacs 창을 최소화한다(`suspend-frame`). 실수로 눌렀으면 작업 표시줄에서 Emacs를 다시 연다.

## 2. 시작과 화면 구성

### 시작

```
E:\Work\Dev\01.c_study\emacs.bat                  공부 폴더를 연다
E:\Work\Dev\01.c_study\emacs.bat c\01_hello.c     파일을 바로 연다 (없는 이름이면 새 파일)
```

`emacs.bat`는 `shell.bat`로 Visual Studio 2022 빌드 환경을 준비한 뒤 공부 폴더에서 Emacs를 연다. 처음 파일을 열 때의 폴더는 공부 폴더이다.

### 화면

- 창이 최대화되고 **좌우 두 개의 창(window)**으로 나뉘어 열린다. `M-f`로 파일을 연다([5절](#5-파일과-버퍼)).
- 아래쪽 회색 줄(모드 줄)에 파일 이름, 줄 번호, 시계, **현재 프로그램**(`[01_hello.c]`)이 보인다. 그 아래 한 줄은 미니버퍼(명령 입력과 메시지)이다.
- 화면 왼쪽에 줄 번호가 보인다(`emacs_edit.el`).
- 커서가 있는 줄은 조금 밝은 회색 바탕으로 강조된다. 주석의 `TODO`는 빨강, `NOTE`는 초록, `STUDY`와 `IMPORTANT`는 노랑으로 보인다(모두 굵게, 밑줄).
- 빌드 결과, 검색 결과 같은 창은 새로 나뉘지 않고 **다른 쪽 창**에 나온다.

### 글꼴과 색 (emacs_theme.el)

`emacs_theme.el`이 Emacs의 글꼴과 C/C++ 색을 gvim(`gvim_handmade.vim`)과 같게 맞춘다. Handmade Hero 날짜 폴더 `misc\emacs_theme.el`의 사본이고, `emacs_c_study.el`이 마지막에 읽는다. 외부 패키지 없이 Emacs에 들어 있는 기능만 쓴다.

| 항목 | 내용 |
|---|---|
| 글꼴 | JetBrainsMono Nerd Font Mono 12(Windows 이름 `JetBrainsMono NFM`). 없으면 Consolas 12. 한글은 맑은 고딕 |
| 바탕 / 글자 | `#1E1E1E` / `#DADADA`. 커서 줄 `#282828`, 모드 줄 `#3C3C3C` |
| 코드 색 | `if` `for` `return` 등 보라, `int` `void` `struct` `const` 등 파랑, 이름 카키, `(` 앞의 이름(함수) 주황, 숫자와 상수 연한 녹색, 문자열 살구색, 주석 초록, 전처리 줄 회색, `#if 0` 블록은 주석색 |
| 글꼴 크기 | **`Ctrl` + 마우스 휠 위 / 아래**로 1포인트씩 크게 / 작게(6 ~ 40). 모든 창에 같이 적용되고 Emacs를 다시 열면 12 |

gvim처럼 `.c` 파일과 C++ 문법이 없는 `.h` 파일은 C로, `.cpp`는 C++로 보고 그 언어의 키워드만 키워드 색으로 칠한다. `std::cout`의 `std`, `Scores::Add`의 `Scores`도 gvim처럼 이름 색(카키)이다.

### 창 사이 이동과 나누기

| 키 | 기능 |
|---|---|
| `M-w` | 다른 쪽 창으로 커서 이동 (`C-x o`와 같다) |
| `C-<next>` / `C-<prior>` | 커서는 그대로 두고 **다른 쪽 창**을 아래로/위로 스크롤 (빌드 결과를 볼 때) |
| `C-x 1` | 지금 창 하나만 남기기 (다른 창의 버퍼는 닫히지 않는다) |
| `C-x 3` | 좌우로 나누기 (처음 모습으로 되돌릴 때) |
| `C-x 2` | 위아래로 나누기 |
| `C-x 0` | 지금 창 닫기 |
| `C-x }` / `C-x {` | 지금 창을 넓게/좁게 (반복해서 누른다) |

## 3. 기본 Emacs와 다른 키

Casey의 설정이 바꿔 둔 키 가운데 일반 Emacs 설명과 달라서 특히 헷갈리는 것들이다.

| 키 | 이 환경에서 | 일반 Emacs에서 | 일반 Emacs 기능을 쓰려면 |
|---|---|---|---|
| `C-f` | **붙여넣기** (`yank`) | 한 글자 앞으로 | `→` 화살표 |
| `C-y` | **현재 줄 들여쓰기** | 붙여넣기 | 붙여넣기는 `C-f` 또는 `M-a` |
| `C-q` | **복사** (`copy-region-as-kill`) | 다음 글자를 그대로 입력 | `M-x quoted-insert` |
| `C-e` | 붙여넣을 항목을 하나 앞 것으로 돌리기 | 줄 끝으로 | `End` |
| `M-w` | **다른 창으로 이동** | 복사 | 복사는 `C-q` |
| `M-f` / `M-b` | **파일 열기 / 버퍼 바꾸기** | 단어 앞/뒤로 | `C-→` / `C-←` |
| `M-a` | **붙여넣기** | 문장 처음으로 | `M-x c-beginning-of-statement` |
| `M-z` | **잘라내기** (`C-w`와 같다) | 글자까지 지우기 | `M-x zap-to-char` |
| `M-q` | 영역을 마지막 복사 내용 **뒤에 덧붙여 복사** | 문단 채우기 | 문단 채우기는 `M-.` |
| `M-;` | 커서와 표시(mark) 위치 바꾸기 | 주석 넣기 | 주석은 `C-c C-c` ([11절](#11-들여쓰기-자동-완성-주석)) |
| `M-:` | 표시 위치로 돌아가기 | Lisp 식 계산 | `M-x eval-expression` |
| `M-.` | 주석·문단 다시 줄 맞춤 | 정의로 이동 | `C-x 4 .` ([7절](#7-함수-정의-include-파일로-이동)) |
| `M-/` (C/C++ 파일) | **함수 전체 선택** | 단어 자동 완성 | 자동 완성은 `TAB` |
| `TAB` | **단어 자동 완성**. 닫는 괄호 앞이면 빠져나가기 | 들여쓰기 | 들여쓰기는 `C-y`, `S-TAB` |
| `M-u` | **실행 취소** | 단어를 대문자로 | 대문자는 `M-6` |
| `M-s` | **저장** | 검색 명령 앞부분(`M-s o` 등) | `M-x occur` |
| `M-o` | 확인하며 치환 | (없음) | |
| `M-g` | **줄 번호로 이동** | `M-g g` 등의 앞부분 | |
| `M-m` | **현재 프로그램 빌드** | 줄의 첫 글자로 | `M-x back-to-indentation` |
| `M-k` | 버퍼 닫기 → **Emacs 31에서는 오류** | 문장 끝까지 지우기 | 버퍼 닫기는 `C-x k RET` |
| `M-^` | 첫 글자 대문자 → **동작하지 않음** | 줄 합치기 | `M-x capitalize-word`, `M-x delete-indentation` |

그 밖의 차이:

- **선택 영역이 색으로 보이지 않는다.** `C-SPC`를 누르면 Casey의 설정이 영역 강조(transient-mark-mode)를 끈다. 영역의 범위는 `C-x C-x`로 양 끝을 오가며 확인한다([8절](#8-영역-선택)).
- **Shift+화살표로 선택하지 않는다.**
- **`M-k`가 동작하지 않는 이유:** Casey는 `M-k`에 `kill-this-buffer`를 연결했는데, Emacs 31부터 이 명령은 메뉴나 도구 모음에서만 실행되고 키로 부르면 "This command must be called from a menu or a tool bar" 오류를 낸다. 같은 일은 `C-x k RET`로 한다.
- **`M-^`가 동작하지 않는 이유:** Casey의 설정에 함수 이름이 `captilize-word`로 잘못 적혀 있다.

## 4. 빌드, 실행, 디버그

공부 폴더에서 더한 키이다. 대상은 **현재 프로그램**, 즉 마지막으로 화면에 띄운 `.c` 또는 `.cpp` 파일이다(모드 줄의 `[이름]`). `.h` 파일, 빌드 결과 창으로 옮겨도 현재 프로그램은 바뀌지 않는다.

| 키 | 기능 |
|---|---|
| `M-m` | **현재 프로그램 빌드** (`build.bat "소스 파일"`). 결과는 다른 쪽 창의 `*compilation*`에 나온다. 저장하지 않은 파일이 있으면 저장할지 묻는다(`y` 저장, `!` 모두 저장) |
| `F5` | **실행.** 새 콘솔 창에서, 소스 파일이 있는 폴더에서 실행한다. 끝나면 종료 코드를 보여 주고 키를 기다린다 |
| `C-<f5>` | **빌드한 뒤 성공하면 실행** |
| `S-<f5>` | 실행 중인 현재 프로그램 강제 종료 (무한 반복, 입력 대기 등) |
| `F6` | **Visual Studio 2022 디버거로 열기.** 사용 순서는 `Emacs_C_C++_가이드.md` 9절 |
| `M-x recompile` | 마지막 빌드를 다시 (`*compilation*` 창 안에서는 `g`) |
| `M-x kill-compilation` | 진행 중인 빌드 중지 |

- 빌드 결과는 소스 파일 옆의 `build\이름.exe`이다(`c\04_test.c` → `c\build\04_test.exe`).
- 프로그램이 실행 중이면 빌드가 `is running`으로 멈춘다(메시지에는 "Shift+F5 in gvim"이라고 나온다). `S-<f5>`로 끄거나 실행 창에서 키를 누른 뒤 다시 빌드한다.

### 오류 위치로 이동

| 키 | 기능 |
|---|---|
| `F9` | 첫 번째 오류로 이동 |
| `M-n`, `F11`, ``C-x ` `` | 다음 오류로 이동. 오류가 있는 파일이 열리고 그 줄로 간다 |
| `M-N`, `F10` | 이전 오류로 이동 |
| `RET` (`*compilation*` 창에서) | 커서가 있는 오류 줄의 위치로 이동 |

- 컴파일러 메시지는 한글로 나온다(예: `error C2146: 구문 오류: ';'이(가) 'printf' 식별자 앞에 없습니다.`).
- `;`가 빠진 오류는 **그다음 줄**이 오류 위치로 나온다.
- `M-n`, `M-N`은 마지막에 쓴 목록을 따라간다. 빌드 뒤에는 오류 목록, `M-x grep`이나 `M-x occur` 뒤에는 검색 결과 목록이다([12절](#12-검색과-치환)).

## 5. 파일과 버퍼

버퍼는 Emacs 안에 열려 있는 파일(또는 빌드 결과 같은 내용)이다. 창을 닫아도 버퍼는 남아 있다.

### 파일 열기와 버퍼 바꾸기

| 키 | 기능 |
|---|---|
| `M-f` | 파일 열기 (`ido-find-file`). `C-x C-f`와 같다 |
| `M-F` | 다른 쪽 창에 파일 열기 |
| `M-b` | 열려 있는 버퍼로 바꾸기. `C-x b`와 같다 |
| `M-B` | 다른 쪽 창에서 버퍼 바꾸기 |
| `C-x C-b` | 버퍼 목록 보기 (목록에서 `RET`으로 열기) |
| `M-c`, `F12` (C/C++) | 같은 이름의 `.c`/`.cpp` ↔ `.h` 전환. 같은 이름의 `.h`가 없으면 빈 `.h` 버퍼가 새로 열린다(저장하지 않으면 파일은 생기지 않는다) |
| `M-C`, `M-<f12>` (C/C++) | 대응 파일을 다른 쪽 창에 열기 |

`M-f`, `M-b`에서 쓰는 키 (ido):

| 키 | 기능 |
|---|---|
| 이름 일부 입력 | 아래 후보 목록이 그 글자를 포함하는 것으로 좁혀진다. `c/01_h` `RET` → `c\01_hello.c` |
| `/` | **폴더 구분은 `/`로 입력한다.** `c/`까지 치면 c 폴더로 들어간다. `\`로 입력하면 엉뚱한 파일이 열릴 수 있다 |
| `C-s` / `C-r` | 다음 / 이전 후보로 |
| `TAB` | 공통 부분까지 완성, 후보 목록 보기 |
| `RET` | 첫 번째 후보 열기 |
| `C-j` | 입력한 이름 그대로 열기 (**새 파일을 만들 때**) |
| `DEL` (입력이 비었을 때) | 위 폴더로 |
| `C-g` | 취소 |

`M-f`는 **지금 보고 있는 파일의 폴더**에서 시작한다. Emacs를 처음 열었을 때는 공부 폴더이므로 `c/01_h`처럼 폴더부터 입력한다. `c\01_hello.c`를 보고 있을 때는 `c` 폴더에서 시작하므로 `02_input.c`처럼 이름만 입력한다. 다른 폴더(`cpp` 등)로 가려면 입력이 빈 상태에서 `DEL`로 공부 폴더로 올라간 뒤 `cpp/`를 입력한다.

### 새 파일

`M-f`로 `c/04_test.c`처럼 없는 이름을 입력하고(`c` 폴더의 파일을 보고 있으면 `04_test.c`만) `C-j`를 누르면 새 파일이 열리고 `main` 틀이 들어간다. 커서는 `main` 안의 빈 줄에 있다.

```c
#include <stdio.h>

int
main(void)
{
    
    return(0);
}
```

`.cpp`는 `#include <iostream>`과 `main()`으로 시작하고, 새 `.h`는 빈 파일로 시작한다.

### 저장, 다시 읽기, 닫기

| 키 | 기능 |
|---|---|
| `M-s` | 저장. C/C++ 파일은 탭을 공백으로 바꾼 뒤 저장한다 |
| `C-x C-s` | 저장 (일반 Emacs 키) |
| `C-x s` | 수정된 모든 버퍼를 하나씩 물어보며 저장 |
| `C-x C-w` | 다른 이름으로 저장 (예제를 고쳐 내 파일로 저장할 때). 이름을 입력하고 `C-j` |
| `M-r` | 디스크의 내용으로 다시 읽기. 저장하지 않은 변경은 버린다. `yes`를 입력해 확인한다 |
| `C-x k RET` | **현재 버퍼 닫기.** 수정된 파일이면 저장할지 묻는다 (`M-k`는 Emacs 31에서 오류) |

자동 저장과 백업 파일(`~` 파일)은 꺼져 있다. 자주 `M-s`로 저장한다.

## 7. 함수, 정의, #include 파일로 이동

### 현재 파일의 함수

| 키 | 기능 |
|---|---|
| `M-j` | **함수 이름으로 이동** (`imenu`). 이름 일부를 입력하고 `TAB`으로 완성, `RET`으로 이동. 예: `M-j main RET` |
| `C-M-a` | 지금 함수의 처음으로 (다시 누르면 이전 함수) |
| `C-M-e` | 지금 함수의 끝으로 (다시 누르면 다음 함수 끝) |
| `C-x n d` / `C-x n w` | 지금 함수만 보이게 좁히기 / 다시 전체 보기 |

`M-j`의 목록은 현재 파일에 정의된 함수와 구조체이다. 새 파일 틀처럼 함수 이름을 줄 처음에 쓰면(`int` 다음 줄에 `main(void)`) 목록에 잘 나온다.

### 다른 파일에 있는 정의로 이동 (TAGS)

내 헤더(`.h`)에 만든 함수나 다른 예제 파일의 함수로 바로 가려면 TAGS 파일을 한 번 만든다.

1. 공부 폴더의 TAGS를 만든다. 공부 폴더 바로 아래의 파일(또는 `C-x d`로 연 공부 폴더 목록)에서:
   ```
   M-! dir /b /s *.c *.cpp *.h | etags - RET
   ```
   공부 폴더에 `TAGS` 파일이 생긴다(Emacs에 들어 있는 `etags.exe`가 만든다). `/s`라서 `c\`, `cpp\` 등 하위 폴더까지 모두 들어간다. `etags *.c`처럼 쓰면 `*`가 풀리지 않아 빈 TAGS가 생기므로 위 형태로 쓴다.
   `c\`나 `cpp\`의 파일을 연 상태라면 `M-! cd .. && dir /b /s *.c *.cpp *.h | etags - RET`로 공부 폴더에 만든다.
2. TAGS를 읽는다. `M-x visit-tags-table RET`. 미니버퍼에 기본값이 보이면 공부 폴더의 `TAGS`인지 확인하고 `RET`(다른 폴더면 공부 폴더의 `TAGS` 경로로 고친다)
3. 이동한다.

| 키 | 기능 |
|---|---|
| `C-x 4 .` | **커서 아래 이름의 정의로 이동** (다른 쪽 창에 연다). 커서가 이름 위에 있으면 묻지 않고 바로 간다. 이름 위가 아니면 미니버퍼에 이름을 입력하고 `RET` (`TAB`으로 완성). 다른 이름을 입력하려면 `C-u C-x 4 .` |
| `M-x xref-find-definitions RET` | 정의로 이동 (지금 창에서 연다. Casey 설정에서는 `M-.`가 다른 기능이라 이름으로 부른다) |
| `M-,` | **정의로 가기 전 위치로 돌아오기** |

- 같은 이름의 정의가 여러 개면 목록 창이 열린다. `n`/`p`로 고르고 `RET`. 여러 예제에 같은 이름의 함수(`main` 등)가 있으면 목록이 나온다.
- 함수를 새로 만들거나 많이 고친 뒤에는 1번을 다시 실행해 TAGS를 새로 만든다. `TAGS`는 필요 없으면 지워도 된다.

### #include 파일로 이동

| 방법 | 기능 |
|---|---|
| `M-x ff-find-other-file RET` | `#include "my_lib.h"` 같은 **따옴표 `#include` 줄 아무 곳에서** 실행하면 그 파일을 연다 |
| `M-x ffap RET RET` | 커서를 따옴표 안의 파일 이름 위에 두고 실행하면 미니버퍼에 그 파일 경로가 채워진다. `RET`으로 연다 |
| `M-c`, `F12` | 지금 파일과 같은 이름의 `.h`/`.c`로 (`#include`와는 무관) |

- `#include <stdio.h>`, `<iostream>` 같은 **표준 헤더는 이 두 명령으로 열리지 않는다**(이 환경에서 확인). 표준 함수의 사용법은 Visual Studio 도움말이나 교재를 본다.
- 돌아올 때는 `M-b RET`(바로 전 버퍼가 첫 후보) 또는 `C-x C-SPC`를 쓴다.

### 이름이 쓰인 곳 찾기

| 방법 | 기능 |
|---|---|
| `M-x occur RET 이름 RET` | **현재 파일**에서 그 글자가 있는 줄 목록. 목록에서 `RET`, 또는 `M-n`/`M-N`으로 차례로 이동 |
| `M-x grep RET` | **폴더 검색.** 미니버퍼에 `findstr -s -n -i -l `가 들어 있다. `C-a C-k`로 지우고 아래 명령을 입력한 뒤 `RET`. 결과 목록에서 `RET`, 또는 `M-n`/`M-N` |
| `C-s` | 현재 파일에서 다음 위치 ([12절](#12-검색과-치환)) |

`M-x grep`에 넣을 명령:

| 현재 파일의 위치 | 명령 | 찾는 범위 |
|---|---|---|
| `c\` 또는 `cpp\` 안의 파일 | `findstr -s -n -i 이름 ..\*.c ..\*.cpp ..\*.h` | 공부 폴더 전체 |
| `c\` 또는 `cpp\` 안의 파일 | `findstr -s -n -i 이름 *.c *.cpp *.h` | 그 폴더만 |
| 공부 폴더 바로 아래의 파일 | `findstr -s -n -i 이름 *.c *.cpp *.h` | 공부 폴더 전체 |

`-s`는 하위 폴더 포함, `-i`는 대소문자 무시, `-n`은 줄 번호이다. 기본값의 `-l`은 파일 이름만 보여 주므로 빼고 쓴다. 띄어쓰기가 있는 문구는 `/c:"두 단어"`로 쓴다. 공부 폴더 바로 아래의 파일에서 `..\*.c`를 쓰면 공부 폴더 바깥까지 찾으므로 쓰지 않는다.

## 8. 영역 선택

Emacs에서 선택 영역(region)은 **표시(mark)와 커서(point) 사이**이다. 표시를 놓고 커서를 옮기면 그 사이가 영역이 된다.

| 키 | 기능 |
|---|---|
| `C-SPC`, `M-SPC` | **여기에 표시 놓기** (선택 시작). 미니버퍼에 `Mark set`이 나온다 |
| `C-x C-x`, `M-;` | 커서와 표시를 맞바꾸기. 영역의 다른 끝으로 가 보며 범위를 확인한다 |
| `M-h` | 지금 문단(빈 줄 사이) 선택 |
| `M-/`, `C-M-h` (C/C++) | **지금 함수 전체 선택** (반환형 줄 포함) |
| `C-M-SPC` | `{` 위에서 누르면 짝이 맞는 `}`까지 선택 (괄호 블록) |
| `C-x h` | 파일 전체 선택 |
| `C-x SPC` | 사각형(열) 선택 시작 ([9절](#9-복사-잘라내기-붙여넣기)의 사각형 명령과 함께) |

- 이 환경은 **선택 영역을 색으로 보여 주지 않는다**(Casey의 설정). 표시를 놓은 뒤 커서를 옮기고, 필요하면 `C-x C-x`로 양 끝을 확인한다.
- 영역을 정한 뒤 복사(`C-q`), 잘라내기(`C-w`), 들여쓰기(`C-<tab>`), 주석(`C-c C-c`) 같은 명령을 쓴다.

## 9. 복사, 잘라내기, 붙여넣기

Emacs는 잘라내거나 복사한 내용을 목록(kill ring)에 쌓아 둔다. Windows 클립보드와도 연결되어 있어서 교재 예제나 다른 프로그램의 코드를 주고받을 수 있다.

| 키 | 기능 |
|---|---|
| `C-q` | **영역 복사** |
| `C-w`, `M-z` | **영역 잘라내기** |
| `C-f`, `M-a` | **붙여넣기** (마지막으로 복사하거나 잘라낸 내용, 또는 Windows에서 복사한 내용) |
| `M-y` | 붙여넣기 직후에 누르면 방금 붙인 것을 **그 전 항목으로 바꾼다.** 계속 누르면 더 이전 항목 |
| `M-q` | 영역을 마지막 복사 내용 **뒤에 덧붙여** 복사. 떨어진 두 곳을 한 번에 붙여넣을 때 |
| `C-e` | 다음 붙여넣기 대상을 이전 항목으로 돌리기 |

`C-k`(줄 끝까지 지우기), `M-d`(단어 지우기) 같은 지우기 명령도 내용을 목록에 넣는다. 연달아 지운 내용은 하나로 합쳐진다. 예를 들어 줄 처음에서 `C-k`를 여섯 번 누르면(한 줄에 두 번: 내용, 줄바꿈) 세 줄이 지워지고, `C-f` 한 번으로 세 줄을 다시 붙여넣을 수 있다.

### 사각형(열) 단위

여러 줄의 같은 열을 다룬다. 사각형의 한 모서리에서 `C-SPC`, 반대쪽 모서리로 커서를 옮긴 뒤:

| 키 | 기능 |
|---|---|
| `C-x r M-w` | 사각형 복사 |
| `C-x r k` | 사각형 잘라내기 |
| `C-x r y` | 사각형 붙여넣기 (커서가 왼쪽 위 모서리) |
| `C-x r d` | 사각형 지우기 (목록에 넣지 않음) |
| `C-x r t 글자 RET` | 사각형의 각 줄을 입력한 글자로 바꾸기. 폭이 0이면 각 줄에 끼워 넣는다 (여러 줄 앞에 `// ` 넣기) |
| `C-x r o` | 사각형만큼 공백 끼워 넣기 |

### 레지스터 (이름 붙인 저장 칸)

| 키 | 기능 |
|---|---|
| `C-x r s a` | 영역을 레지스터 `a`에 복사 (a 대신 아무 글자). 자주 쓰는 코드 조각을 담아 둘 때 |
| `C-x r i a` | 레지스터 `a`의 내용을 붙여넣기 |

| `C-d`, `Delete` | 커서 위치 글자 지우기 |
| `DEL` (Backspace) | 앞 글자 지우기 |
| `M-d`, `C-<delete>`, `M-<delete>` | 다음 단어 지우기 |
| `M-DEL` (Alt+Backspace), `C-<backspace>` (Ctrl+Backspace) | 앞 단어 지우기 |
| `C-k` | 커서부터 줄 끝까지 지우기. 줄 끝에서 누르면 줄바꿈을 지운다(아랫줄을 끌어올림) |
| `C-S-<backspace>` (Ctrl+Shift+Backspace) | **줄 전체 지우기** |
| `C-w`, `M-z` | 영역 지우기(잘라내기) |
| `C-M-k` | `{` 앞에서 누르면 짝이 맞는 `}`까지의 블록 지우기 |
| `M-\` | 커서 주변의 공백과 탭 모두 지우기 |
| `C-x C-o` | 연속된 빈 줄을 하나만 남기고 지우기 |
| `C-c C-d` (C/C++) | 커서 뒤의 공백, 탭, 줄바꿈을 한 번에 지우기 |
| `C-t` | 커서 앞뒤 두 글자 바꾸기 |
| `C-x C-t` | 지금 줄과 윗줄 바꾸기 ([14절](#14-자주-쓰는-작업-순서)의 줄 옮기기) |

지운 내용(`C-d`, `DEL` 한 글자 지우기는 제외)은 `C-f`로 다시 붙여넣을 수 있다.

## 11. 들여쓰기, 자동 완성, 주석

### 자동 완성

| 키 | 기능 |
|---|---|
| `TAB` | **단어 자동 완성.** 앞부분을 치고 누르면 열려 있는 파일들에 있는 단어로 완성한다. 다시 누르면 다른 후보로 바뀐다. 예: `prin` `TAB` → `printf` (이미 쓴 단어일 때). C/C++ 파일에서 커서 바로 뒤가 닫는 괄호나 따옴표이면 먼저 그 뒤로 빠져나간다 |
| `M-?` (Alt+Shift+/) | 단어 자동 완성. 괄호 안처럼 `TAB`이 빠져나가기로 쓰이는 곳에서 쓴다 |

### 들여쓰기

| 키 | 기능 |
|---|---|
| `RET` (C/C++) | 줄을 바꾸고 다음 줄을 자동으로 들여쓰기 |
| `C-y`, `S-TAB` (Shift+Tab) | **현재 줄 들여쓰기 정리** |
| `C-<tab>`, `M-TAB`, `C-M-\` | **영역 들여쓰기 정리** |
| `C-c C-q` (C/C++) | 지금 함수 전체 들여쓰기 정리 |
| `M-i` | 다음 탭 위치까지 공백 넣기 |

들여쓰기는 Casey의 스타일(4칸, 공백만, 중괄호는 따로 줄)이다. `TAB`은 들여쓰기가 아니라 자동 완성이라는 점에 주의한다(커서 앞이 단어가 아니면 4칸 공백). 교재 코드를 붙여넣은 뒤에는 `C-x h C-<tab>`(파일 전체 들여쓰기 정리)으로 정리한다.

### 주석

| 키 | 기능 |
|---|---|
| `C-;` (C/C++) | **현재 줄을 `// ` 주석으로 바꾸거나 해제** |
| `C-u C-;` (C/C++) | 커서와 표시(mark) 사이의 줄들을 주석으로 바꾸거나 해제 |
| 영역 선택 후 `C-c C-c` (C/C++) | **영역의 줄마다 `// ` 붙이기** |
| 영역 선택 후 `C-u C-c C-c` | 주석 해제 |
| `M-x comment-region` / `M-x uncomment-region` | 위와 같다 (C/C++ 외의 파일에서도) |
| `M-.` | 긴 주석 문단을 다시 줄 맞춤 |

`M-;`는 이 환경에서 주석 키가 아니다([3절](#3-기본-emacs와-다른-키)).

### C/C++ 편집 편의 기능 (emacs_edit.el)

`emacs_edit.el`이 gvim의 C/C++ 편집 기능을 더한다(Handmade Hero 날짜 폴더 `misc\emacs_edit.el`의 사본). 외부 패키지 없이 Emacs 기본 기능만 쓰고, Casey의 키(`M-;`, `M-d`, `F4`, `M-/` 등)는 그대로이다. 이 폴더의 `M-m`, `F5`, `C-F5`, `S-F5`, `F6`도 그대로이다.

| 입력 / 키 | 동작 (`▮`는 커서) |
|---|---|
| `(` `[` `{` `"` `'` | `(▮)` `[▮]` `{▮}` `"▮"` `'▮'`처럼 닫는 문자가 함께 들어간다. 바로 뒤에 글자가 있거나 주석·문자열 안이면 넣지 않는다 |
| `)` `]` `}`, 닫는 따옴표 | 바로 뒤에 같은 문자가 있으면 그 위를 지나간다(평소대로 쳐도 두 번 들어가지 않는다) |
| `DEL` | 빈 짝 사이(`(▮)`)에서는 짝을 함께 지운다 |
| `{` `}` 사이에서 `RET` | 세 줄로 나뉘고 커서는 가운데 줄에 들여쓰기된다 |
| `TAB` | ① 바로 뒤가 `)` `]` `}`나 닫는 따옴표이면 그 뒤로 빠져나가기 ② 앞이 단어이면 단어 자동 완성 ③ 그 밖에는 4칸 공백. 예: `printf("%d` `TAB` `, 1` `TAB` `;` → `printf("%d", 1);` |
| `M-?` (Alt+Shift+/) | 단어 자동 완성 (괄호 안에서) |
| `M-e` | 커서 앞이 `if` `else` `for` `while` `switch` `case` `struct` `inc`이면 그 코드 조각(중괄호는 따로 줄). 아니면 원래대로 문장 끝으로 |
| `C-;` / `C-u C-;` | 현재 줄 / 커서와 표시 사이의 줄들을 `// ` 주석으로 바꾸거나 해제 |
| `M-D` (Alt+Shift+d) | 현재 줄을 아래에 복제 |
| `M-S-<up>` / `M-S-<down>` | 현재 줄을 위 / 아래로 옮기기 (들여쓰기도 정리) |
| `M-RET` (Alt+Enter) | 커서 위치와 관계없이 아래에 새 줄 |
| `F7` | 커서 아래 단어를 공부 폴더 전체(`c\`, `cpp\` 포함)의 `.c`, `.cpp`, `.h`에서 찾는다. 결과는 다른 쪽 창, `M-n` / `M-N`으로 이동 |
| `C-c @ C-c` | 블록 접기 / 펼치기 (`C-c @ C-M-h` 모두 접기, `C-c @ C-M-s` 모두 펼치기) |
| 줄 번호 | 화면 왼쪽에 보인다. 끄려면 `M-x display-line-numbers-mode` |

모드 줄의 ` gv`는 이 기능이 켜져 있다는 표시이다. 두 파일(`emacs_theme.el`, `emacs_edit.el`)을 지우면 Casey의 원래 모양과 키로 돌아간다.

## 12. 검색과 치환

### 검색

| 키 | 기능 |
|---|---|
| `C-s` | **앞으로 검색** (치는 대로 바로 찾아간다) |
| `C-r` | 뒤로 검색 |
| `C-M-s` / `C-M-r` | 정규식으로 앞 / 뒤 검색 |

검색 중에 쓰는 키:

| 키 | 기능 |
|---|---|
| `C-s` / `C-r` | 다음 / 이전 위치 |
| `C-w` | 커서 뒤의 단어를 검색어에 더하기 (커서 아래 이름을 찾을 때 `C-s C-w C-s`) |
| `DEL` | 검색어 한 글자 지우기 |
| `RET` | 검색 끝 (찾은 위치에 머문다) |
| `C-g` | 검색 취소 (검색 전 위치로 돌아간다) |
| `M-%` | 지금 검색어로 확인하며 치환 시작 |

`C-s`를 처음 누른 뒤 바로 다시 `C-s`를 누르면 지난번 검색어로 찾는다.

### 치환

| 키 | 기능 |
|---|---|
| `M-o`, `M-%` | **확인하며 치환** (커서 이후). 찾을 말 `RET`, 바꿀 말 `RET` |
| `C-M-%` | 정규식으로 확인하며 치환 |
| `M-O`, `F8` | 커서 이후를 **한 번에 모두** 치환 (커서는 제자리에 남는다) |
| `M-l` | **선택 영역 안에서만** 한 번에 모두 치환 (함수 하나 안의 변수 이름 바꾸기 등) |

확인하며 치환할 때의 키:

| 키 | 기능 |
|---|---|
| `y`, `SPC` | 바꾸고 다음으로 |
| `n`, `DEL` | 건너뛰고 다음으로 |
| `!` | 나머지 모두 바꾸기 |
| `.` | 이것만 바꾸고 끝 |
| `q`, `RET` | 끝 |
| `^` | 바로 전 위치로 돌아가기 |

치환은 커서 이후만 대상이다. 파일 전체를 바꾸려면 먼저 `M-<`로 처음으로 간다.

### 목록으로 찾기

`M-x occur`(현재 파일)와 `M-x grep`(폴더)은 [7절](#7-함수-정의-include-파일로-이동)에 있다.

## 13. 실행 취소, 대소문자, 매크로, 계산기

### 실행 취소

| 키 | 기능 |
|---|---|
| `M-u`, `C-/`, `C-_` | **실행 취소.** 계속 누르면 더 이전으로 |
| `C-?` (Ctrl+Shift+/), `C-M-_` | 다시 실행 (실행 취소를 되돌리기) |

Emacs에서는 실행 취소도 하나의 편집이다. 실행 취소 중에 커서를 움직이는 등 다른 명령을 한 번 하면, 그다음 `M-u`는 방금 한 실행 취소들을 되돌리는 쪽으로 진행한다.

### 대소문자

| 키 | 기능 |
|---|---|
| `M-6` | 커서 뒤 단어를 대문자로 (`#define` 상수 이름 등) |
| `M-x capitalize-word` | 첫 글자만 대문자로 (`M-^`는 동작하지 않음) |
| `C-x C-u` / `C-x C-l` | 영역을 대문자 / 소문자로. 처음 쓰면 "disabled command"라며 물어본다. `SPC`(이번 한 번) 또는 `!`(이번 실행 동안 계속)를 누른다. `y`는 설정 파일에 기록하려 하므로 누르지 않는다 |

### 키보드 매크로 (같은 편집 반복)

| 키 | 기능 |
|---|---|
| `M-[` | 매크로 기록 시작 |
| `M-]` | 기록 끝 |
| `M-'` | 기록한 매크로 실행 |
| `C-u 10 M-'` | 10번 실행 |
| `<f3>` / `<f4>` | 기록 시작 / 기록 끝 또는 실행 (Emacs 기본 키, 위와 같은 기능) |

예: 여러 줄 끝에 `;`를 붙이기 — 첫 줄에서 `M-[` `End` `;` `↓` `M-]`, 그다음 `M-'`를 줄 수만큼 누른다.

### 그 밖의 키

| 키 | 기능 |
|---|---|
| `M-p` | **계산기** (`quick-calc`). `1024*3 RET`처럼 식을 넣으면 아래에 결과가 나온다. 비트 연산이나 자료형 크기 계산을 확인할 때 |
| `M-t` | 공부 폴더의 할 일 파일(`todo.txt`) 열기. 저장해야 파일이 생긴다 |
| `C-x z` | 바로 전 명령 반복 (계속 `z`) |
| `M-!` | 셸 명령 한 번 실행 (결과는 아래 또는 다른 창) |

## 14. 자주 쓰는 작업 순서

|---|---|
| 새 프로그램 만들고 실행 | `M-f` `c/05_test.c` `C-j` (`c` 폴더의 파일을 보고 있으면 `05_test.c`만) → 코드 입력 → `M-s` → `C-<f5>` |

| 예제를 복사해서 내 파일로 | 예제를 연 뒤 `C-x C-w` `06_my.c` `C-j` (예제와 같은 폴더에 새 이름으로 저장되고, 그 파일이 열린다. 원래 예제는 그대로 남는다) |
| 줄 복제 (아래에 같은 줄) | `M-D`, 또는 `C-a` `C-SPC` `C-n` `C-q` `C-f` |
| 줄 지우기 | `C-S-<backspace>` 또는 `C-a` `C-k` `C-k` |
| 줄 잘라서 옮기기 | `C-a` `C-k` `C-k` → 옮길 곳의 줄 처음으로 이동 → `C-f` |
| 줄을 한 줄 위로 | `M-S-<up>`, 또는 `C-x C-t` `C-p` `C-p` |
| 줄을 한 줄 아래로 | `M-S-<down>`, 또는 `C-n` `C-x C-t` `C-p` |
| 여러 줄 복사 | 첫 줄 처음에서 `C-SPC` → 마지막 줄 다음 줄 처음으로 → `C-q` → 붙일 곳에서 `C-f` |
| 빈 줄 사이 덩어리 복사 | 덩어리 안에서 `M-h` `C-q` → 붙일 곳에서 `C-f` |
| 함수 전체 복사 | 함수 안에서 `M-/` `C-q` → 붙일 곳에서 `C-f` |
| 함수 전체 옮기기 | 함수 안에서 `M-/` `C-w` → 옮길 곳에서 `C-f` |
| `{ }` 블록 지우기 | `{` 앞에서 `C-M-k` |
| `{ }` 블록 복사 | `{` 앞에서 `C-M-SPC` `C-q` |
| 커서 아래 단어 복사 | 단어 처음에서 `C-SPC` `C-→` `C-q` |
| 단어 바꿔 쓰기 | 단어 처음에서 `M-d` 뒤 새 단어 입력 |
| 한 줄 주석 처리 / 해제 | `C-;` |
| 여러 줄 주석 처리 / 해제 | 영역 선택 → `C-c C-c` / `C-u C-c C-c`, 또는 `C-u C-;`로 전환 |
| 여러 줄 앞에 글자 넣기 | 첫 줄 처음에서 `C-SPC` → 마지막 줄 처음으로 → `C-x r t 글자 RET` |
| 붙여넣은 것을 들여쓰기 정리 | 붙여넣기 직후 `C-<tab>` (붙인 범위가 영역이 된다) |
| 함수 하나 안의 변수 이름 바꾸기 | 함수 안에서 `M-/` → `M-l` `옛 이름` `RET` `새 이름` `RET` |
| 내 헤더의 함수 정의 보고 돌아오기 | 이름 위에서 `C-x 4 .` → 보고 → `M-,` (TAGS 필요, [7절](#7-함수-정의-include-파일로-이동)) |
| `#include "내헤더.h"` 열고 돌아오기 | `#include` 줄에서 `M-x ff-find-other-file RET` → 보고 → `M-b RET` |
| `.c`와 `.h` 오가기 | `M-c` (다른 창에 열기는 `M-C`) |
| 입력을 기다리는 프로그램 끝내기 | `S-<f5>` |

| 키 | 기능 |
|---|---|
| `C-h k` 다음 키 | 그 키가 무엇을 하는지 보기. 이 문서와 다르게 느껴지면 먼저 확인한다 |

## 16. 한글과 파일 인코딩

- `.c`, `.cpp`, `.h` 파일은 **UTF-8로 읽고 저장**한다(BOM 없음, 줄 끝 CRLF). 영문만 있던 파일에 한글을 넣어도 UTF-8로 저장된다. 모드 줄 맨 왼쪽의 `U`가 UTF-8이라는 표시이다.
- `build.bat`가 소스를 UTF-8로 읽어서, 콘솔에 한글이 그대로 보이고 `scanf`로 한글을 입력받을 수 있다.
- 다른 곳에서 가져온 CP949(EUC-KR) 소스는 한글이 깨져 보인다.

| 키 | 기능 |
|---|---|
| `C-x RET r cp949 RET` | 지금 파일을 CP949로 다시 읽기 |
| `C-x RET f utf-8 RET` | 저장할 때의 인코딩을 UTF-8로 바꾸기 (그다음 `M-s`) |

## 17. gvim 키와 비교

같은 폴더의 gvim(`gvim.bat`)도 Casey의 Emacs 키를 따라 만들었다. 대부분 같은 Alt 키이다.

| 작업 | Emacs | gvim |
|---|---|---|

## 18. 확인 근거

2026-11-13에 이 PC(Windows 11, GNU Emacs 31.1, Visual Studio Community 2022)에서 공부 폴더의 임시 복사본을 `emacs.bat`와 같은 방법(`shell.bat` 뒤 공부 폴더에서 `emacs -q -l emacs_c_study.el`)으로 열어 확인했다.

- **키 연결:** 전역과 C 파일(`c\01_hello.c`)에서 키 약 190개를 확인했다.
  - Handmade Hero Emacs와 비교한 176개 가운데 다른 것은 `M-m`(빌드)과 `F5`(실행)뿐이다.
  - `C-<f5>`, `S-<f5>`, `F6`은 공부 폴더에서 더한 키이다.
- **키 입력을 흉내 내어 실행해서 확인한 것:**
  - `M-j main RET`으로 함수로 이동
  - `#include "zz_lib.h"` 줄에서 `M-x ff-find-other-file RET`, 파일 이름 위에서 `M-x ffap RET RET`
  - `M-x visit-tags-table RET RET` 뒤 `C-x 4 .`로 헤더에 있는 함수 정의로 이동, `M-,`로 돌아오기
  - `C-u C-x 4 . Square RET`로 다른 예제 파일의 함수로 이동
  - `M-m`으로 헤더를 쓰는 프로그램 빌드
  - 줄 복제(`C-a C-SPC C-n C-q C-f`), 함수 복사(`M-/ C-q`), 실행 취소(`M-u`)
  - `M-c`로 같은 이름의 `.h`가 없을 때 빈 버퍼가 열리는 것
- **명령으로 확인한 것:**
  - 함수 처음(`C-M-a`)
  - `M-! dir /b /s *.c *.cpp *.h | etags -`로 TAGS 만들기
  - `M-x grep`의 `findstr -s -n -i 이름 *.c *.cpp *.h`와 결과 위치로 이동, `c\`에서 `..\*.c`로 공부 폴더 전체 찾기
  - `M-x occur`

  - `M-f`의 ido 키 연결(`DEL` 위 폴더, `C-j` 입력 그대로, `C-s`/`C-r`, `TAB`). 공부 폴더에서 `c/04_test.c` `C-j`로 새 파일과 `main` 틀이 생기는 것은 키 입력으로 확인했다
- **다른 문서에서 확인한 것:** 빌드, 실행, 디버그 키와 새 파일 틀, UTF-8 저장은 `Emacs_C_C++_가이드.md` 13절에 있다. 편집 키(이동, 선택, 복사, 삭제, 검색, 치환, 매크로)는 같은 `handmade.emacs`를 쓰는 Handmade Hero Emacs에서 같은 방법으로 확인했다.
